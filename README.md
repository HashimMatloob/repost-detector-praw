# Simple Repost Detector (JavaScript)

A lightweight snoowrap bot that detects reposts using title similarity + exact URL matching.

## Features
- Monitors subreddit for new posts every 5 minutes
- Compares titles using word-overlap similarity
- Checks for exact image/video URL matches
- Adds mod notes when reposts are detected

## Setup
1. Install: `npm install`
2. Configure credentials in `repost-detector.js`
3. Run: `npm start`

## Usage
Deploy on a server or local machine. Monitors your chosen subreddit 24/7.
